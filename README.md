# 销售订单数据分析项目
对销售订单数据做数据分析，使用 Pandas 数据清洗，Matplotlib可视化。

## 项目文件说明
- `saleAnalysis.py`：Python脚本，完整数据分析与绘图程序
- `销售分析.ipynb`：Jupyter Notebook 测试调试代码
- `sales.csv`：原始销售订单数据集
- `.gitignore`：git忽略配置

## 环境依赖
- python >=3.10
- pandas
- matplotlib

## 运行方式
1. 安装依赖
```bash
pip install pandas matplotlib
```

2. 运行脚本
```
python saleAnalysis.py
```
